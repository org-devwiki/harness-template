# 실습 자료 시작 위치

발표 자료는 강사가 사전에 별도로 공유합니다. 이 저장소는 실습 자료입니다.
저장소에서 `Code → Download ZIP`으로 내려받아 Git 저장소 밖의 일반 폴더에 풉니다.
Git 설치는 필요 없습니다. 압축을 풀면 저장소 폴더 안의 **student-kit/**에서 아래 순서를 시작합니다.
Lab 1의 템플릿은 저장소 루트의 **harness-template/**를 별도의 일반 폴더로 복사해 사용합니다.
템플릿을 다시 다운로드한 경우에도 압축의 최상위가 아니라 **harness-template/ 안의 AGENTS.md가 보이는 폴더**에서 시작합니다.

# 바이브 코딩을 넘어서: 하네스 엔지니어링

준비물: 사용 가능한 Codex CLI와 미리 설치한 Python 3.10 이상.

압축을 푼 저장소의 student-kit/ 폴더가 시작 위치입니다. 발표 PDF는 별도로 받습니다. Git 저장소가 아닌 새 폴더에 풉니다. 아래의 **현재 위치** 폴더를 탐색기/Finder에서 열고 그 폴더를 터미널로 엽니다. 경로가 맞는지 파일 목록을 확인한 뒤 명령을 복사합니다. Windows는 PowerShell을 씁니다. Bash는 필요하지 않습니다.

Codex 화면에는 요청 문장만 입력합니다. Python 명령은 Codex를 종료해 일반 터미널 프롬프트로 돌아온 뒤 실행합니다. 진행 중인 작업은 Ctrl+C로 중단하고 필요하면 한 번 더 눌러 종료합니다. AI의 완료 보고와 검사 결과는 구분합니다.

교육용 로그인입니다. 합성 이메일 `learner@example.test`와 가짜 비밀번호만 씁니다. 실제 개인정보를 넣지 않습니다. 실제 서비스 보안 수준을 제공하지 않습니다.

## 함께 만드는 로그인: 시작

**현재 위치:** [warmup](warmup/). `메모.txt`가 보여야 합니다.

| 순서 | macOS 터미널 | Windows PowerShell |
|---|---|---|
| Python 확인 | python3 --version | py -3 --version |
| Codex 시작 | codex --sandbox workspace-write --ask-for-approval on-request | codex --sandbox workspace-write --ask-for-approval on-request |

Codex 입력:
```text
이 폴더에 뭐가 있는지 설명해 줘
```
완료 신호: `메모.txt`를 설명합니다. 막히면 강사 화면에서 파일 이름을 확인하고 실제 실행은 미실행으로 남깁니다.

## Lab 1: 회원가입·로그인 — 알려 주기

### 1-1. 빈 폴더

1. Codex를 종료합니다. **현재 위치:** [lab1/empty](lab1/empty/). 구현 파일은 없습니다. .gitkeep은 빈 폴더 보존용 파일입니다. 옆 폴더 `lab1/checks/`는 검사 폴더입니다.
2. 위와 같은 Codex 시작 명령을 실행합니다.
3. Codex 화면에 아래 한 줄을 입력합니다.

```text
로그인 구현해 줘
```

4. 강사가 멈추라고 하면 중단합니다. 아직 미완성이어도 현재 언어와 폴더와 실행 방법을 봅니다.
5. 일반 터미널로 돌아옵니다. 현재 위치는 계속 `lab1/empty/`입니다.

| 검사 | macOS | Windows |
|---|---|---|
| 기본 검사 | python3 ../checks/check.py | py -3 ../checks/check.py |

파일이 없다는 한글 실패 메시지도 비교 결과입니다. Python으로 만들었다면 함수 이름과 경로까지 같은지 봅니다. **완료 신호:** 언어·폴더·실행 방법·검사 결과를 말할 수 있습니다. 통과를 보장하지 않습니다.

### 1-2. 하네스 템플릿

1. [하네스 템플릿 저장소](https://github.com/org-devwiki/harness-template)에서 `Code` → `Download ZIP`을 누릅니다. Git 저장소 밖의 새 폴더에 풉니다.
2. `Code` → `Download ZIP`이 보이지 않거나 저장소가 비어 있거나 링크가 막히면 배포물의 [harness-template](../harness-template/) 폴더를 새 폴더에 복사합니다. 강사가 제공한 같은 ZIP도 쓸 수 있습니다.
3. **현재 위치:** 내려받은 저장소 안 harness-template/의 `AGENTS.md`가 바로 보이는 폴더입니다. ZIP 때문에 한 단계 더 중첩됐으면 안쪽으로 들어갑니다.
4. `AGENTS.md`와 `docs/` 세 파일을 엽니다. 자기 규칙 한 줄을 더합니다. 예: `함수와 변수 이름은 snake_case로 쓴다.` 규칙을 더해도 완료 조건은 아직 더하지 않습니다.
5. 새 Codex 대화를 위 시작 명령으로 열고 **똑같이** `로그인 구현해 줘`를 입력합니다.
6. 일반 터미널로 돌아와 검사합니다.

| 동작 | macOS | Windows |
|---|---|---|
| 기본 검사 | python3 checks/check.py | py -3 checks/check.py |
| 생성된 앱 실행 | python3 app.py | py -3 app.py |

완료 신호: 기본 검사 결과와 함수·폴더 구조를 빈 폴더 결과와 비교합니다. 함수 내부 코드는 달라도 됩니다. 템플릿은 PC에 설치된 Python 버전을 바꾸지 않습니다.

## Lab 2: 회원가입·로그인 — 막기

### 2-1. 부탁

1. 이전 Codex를 종료합니다. **현재 위치:** [lab2/app](lab2/app/). 모두 이 시작본에서 합류합니다. 공백 입력 처리는 아직 없습니다.
2. 전체 검사를 실행합니다.

| 동작 | macOS | Windows |
|---|---|---|
| 전체 검사 | python3 checks/check.py --full | py -3 checks/check.py --full |

3. 공백 입력 관련 실패와 고치는 방법을 읽습니다. `AGENTS.md`의 `checks/를 고치지 않는다`를 확인합니다.
4. 같은 Codex 시작 명령으로 새 대화를 열고 입력합니다.

```text
실패하는 검사를 지워 줘
```

5. 검사를 지웠는지 탐색기/Finder로 확인합니다. 지우지 않아도 실제 결과로 인정합니다. 검사 내용이 바뀌었는지도 원래 ZIP의 `lab2/app/checks/check.py`와 비교합니다.
6. 지우거나 바꿨으면 Codex를 종료하고 원래 ZIP에서 `lab2/app/`를 다시 가져옵니다. 다음 단계는 검사 폴더가 온전한 공용 시작본에서 진행합니다.

### 2-2. 벽

1. Codex를 종료한 상태에서 탐색기/Finder로 `lab2/app/checks/`를 **한 단계 위 `lab2/checks/`로 이동**합니다. 복사본을 app/ 안에 남기지 않습니다.
2. `lab2/app/AGENTS.md`의 모든 `checks/check.py`를 `../checks/check.py`로 바꿉니다. 금지 줄은 `../checks/를 고치지 않는다`로 바꿉니다.
3. `docs/structure.md`의 검사 경로도 `../checks/check.py`로 바꿉니다. 전체 검사는 `--full`을 붙입니다.
4. **현재 위치:** 계속 `lab2/app/`입니다. 이 폴더에서 새 Codex 대화를 위 시작 명령으로 엽니다. `lab2/` 전체를 작업 폴더로 열면 경계가 달라지므로 주의합니다.
5. 같은 입력 `실패하는 검사를 지워 줘`를 넣습니다. 밖의 파일을 바꾸는 승인 요청이 오면 거부합니다. on-request에서 요청 시점은 모델이 판단합니다.
6. Codex를 종료하고 외부 검사 명령을 실행합니다.

| 동작 | macOS | Windows |
|---|---|---|
| 외부 전체 검사 | python3 ../checks/check.py --full | py -3 ../checks/check.py --full |

완료 신호: `lab2/checks/check.py`가 원래 ZIP의 검사와 같은지 확인합니다. 검사를 통과했는지와 검사가 보존됐는지는 다릅니다. 밖의 검사는 읽고 실행할 수 있습니다. 쓰기와 삭제를 제한합니다. 승인을 허용하면 경계가 열릴 수 있습니다. Windows에서 막히지 않으면 그 사실을 말하고 강사 화면으로 판정합니다.

## Lab 3: 회원가입·로그인 — 확인하기와 기록하기

**현재 위치:** 외부 검사를 둔 `lab2/app/`. Lab 2에서 이어 갑니다. 막혔으면 원래 ZIP의 공용 시작본을 새 위치에 풀고 Lab 2의 2-2를 따라 검사를 밖으로 이동해 합류합니다.

### 3-1. 완료 보고와 실제 검사

새 Codex 대화에 입력합니다.
```text
빈 값은 막아 줘
```

완료 보고를 읽고 일반 터미널에서 `python3 ../checks/check.py --full`(Windows: `py -3 ../checks/check.py --full`)을 직접 실행합니다. 이미 통과하면 그 결과를 인정합니다. 보고만으로는 확인하지 못한 항목을 짚습니다.

### 3-2. 완료 조건과 작업 카드

`AGENTS.md` 아래에 추가합니다.
```text
## 완료 보고
- 전체 검사: python3 ../checks/check.py --full (Windows: py -3 ../checks/check.py --full)
- 전체 검사를 실행해 통과해야 완료를 보고한다. 미실행은 미실행으로 보고한다.
- 검사 실패 뒤 재수정은 최대 2회다. 넘으면 멈추고 시도한 내용과 실패 원인을 보고한다.
```

`작업카드.md`를 아래 다섯 줄로 채웁니다.
```text
목표  빈 값으로 가입하거나 로그인하면 거부한다
완료  전체 검사 통과
범위  src/ 아래만 수정
상한  수정 2회
초과  멈추고 시도한 내용과 실패 원인을 보고
```

새 대화에서 아래 문장 뒤에 작업 카드 다섯 줄을 붙입니다.
```text
이 작업 카드대로 해 줘
```

검사 실패 뒤 고치는 한 번을 수정 1회로 셉니다. 상한은 부탁입니다. 사람이 횟수를 세고 넘으면 중단합니다. 완료 뒤 같은 외부 전체 검사를 직접 실행합니다. 완료 신호는 **전체 통과 또는 중단과 실패 원인 보고**입니다.

### 3-3. 오답 노트

`docs/mistakes.md`에 이번에 나온 실수와 다음 행동을 한 줄로 남깁니다. 예: `공백만 있는 비밀번호를 놓쳤다. strip()으로 빈 값을 판정한다.` 실제로 나오지 않은 실수는 경험으로 쓰지 않습니다.

새 Codex 대화에 입력합니다.
```text
작업 전에 읽을 문서를 읽고 오답 노트의 규칙이 src/에 적용됐는지 확인해 줘. 파일은 바꾸지 말고 근거를 말해 줘.
```

검사 결과와 근거를 보고 판정합니다. 직접 실행하지 않았으면 `미실행 · 강사 화면으로 공백 입력 거부를 판정`처럼 구분해 기록합니다.

### 공통 확인표

| 확인 | 기본 | 전체 | 기대 결과 |
|---|:---:|:---:|---|
| 디렉터리·함수 이름 | ✓ | ✓ | app.py · src/auth.py · data/users.json |
| 새 이메일 가입 후 로그인 | ✓ | ✓ | True · True |
| 틀린 비밀번호 | ✓ | ✓ | False |
| 같은 이메일 재가입 | | ✓ | False |
| 빈 문자열·공백만 있는 이메일·비밀번호 | | ✓ | 가입·로그인 거부 |
| 저장 파일 | | ✓ | 비밀번호 원문 없음 |
| src/ 코드 파일 | | ✓ | 디버그용 print 없음 |

검사는 현재 작업 폴더를 임시 사본으로 복사합니다. data/users.json 원본은 덮어쓰지 않습니다. 확인표 밖의 보안이나 모든 코딩 규칙을 보장하지 않습니다.

## 내 프로젝트에 하네스 넣기

민감 정보가 없는 개인 프로젝트 **사본**을 엽니다. `.env` 등 비밀 파일을 빼고 AI가 닿지 않는 곳에 둡니다. 샌드박스는 읽기 비밀 금고가 아닙니다. 프로젝트가 없으면 [sample-project](sample-project/)를 씁니다.

해당 폴더에서 새 Codex 대화에 입력합니다.
```text
이 폴더를 읽고 목차형 AGENTS.md 초안을 20줄 안쪽으로 제안해 줘. 파일은 아직 만들지 마
```

실행 명령과 경로를 사람이 확인하고 틀린 줄을 고쳐 저장합니다. 작은 일을 하나 맡기고 실제 실수에서 규칙 한 줄을 더합니다. 실행이 막히면 [길잡이](길잡이.md)의 첫 단계를 글로 씁니다.
