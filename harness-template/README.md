# 로그인 하네스 템플릿

새 폴더에 ZIP을 풉니다. 이 폴더에서 Codex를 시작하고 `로그인 구현해 줘`를 입력합니다.

- macOS: `codex --sandbox workspace-write --ask-for-approval on-request`
- Windows: 같은 Codex 명령을 씁니다.
- 구현 뒤 기본 검사: macOS `python3 checks/check.py` / Windows `py -3 checks/check.py`
- 실행: macOS `python3 app.py` / Windows `py -3 app.py`

AGENTS.md와 docs/를 먼저 읽습니다. 작업카드는 뒤 단계에서 채웁니다.
교육용 로그인입니다. 합성 계정만 쓰세요. 실제 서비스의 보안 수준을 제공하지 않습니다.
